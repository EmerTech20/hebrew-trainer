# Hebrew Exam Trainer

An installable training app for Biblical Hebrew (Intro to Hebrew Exegesis: Ruth). It runs in the browser, works offline,
and keeps all progress on the device (optional sync between devices).

Open: https://emertech20.github.io/hebrew-trainer/

Word analysis uses the Open Scriptures Hebrew Bible (WLC text and morphology) and the Open Scriptures Hebrew Lexicon,
CC BY 4.0. English verse translations: World English Bible (public domain).
